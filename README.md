# taller_corte_3

Maquetación del flujo de login y registro. Los datos se validan en la app y no hay servidor.

## Versiones

- Flutter 3.44.9
- Dart 3.12.2

## Cómo ejecutarlo

Dentro de la carpeta `taller_corte_3`:

```bash
flutter pub get
flutter run
```

La vista de referencia es 390 × 844. En una ventana más ancha el contenido se mantiene centrado, con un ancho máximo de 430.
